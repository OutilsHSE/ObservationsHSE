# CR HSE — Observations HSE · CDES

Page publique du compte rendu de visite HSE (GitHub Pages). Version V2 du 05/10/2026.

| Fichier | Rôle |
|---|---|
| `index.html` | la page (structure seulement) |
| `css/cr.css` | la mise en forme |
| `js/cr.js` | l'application : CR en brouillon, observations, envoi au PA, mode vocal |
| `js/rapport.js` | le rapport imprimable / export PDF |
| `js/demarrage.js` | l'installation en application (service worker) |
| `swcr.js`, `crhse.webmanifest`, `iconcr*.png` | application installable et hors connexion |

**Ce dépôt ne contient ni adresse de serveur, ni mot de passe, ni nom de personne.**
L'appareil est « branché » en ouvrant le CR depuis la tuile de l'intranet HSE.
La liste des conducteurs de travaux et le nom du visiteur HSE arrivent du serveur,
depuis le Référentiel CDES, seulement sur un appareil branché.
